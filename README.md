# 안녕하세요, 이재휴입니다 👋

**경영학을 전공하고, 현업의 문제를 직접 풀어보기 위해 프로그래밍을 처음 배우고 있습니다.**

제조·유통과 온라인 판매 업무에서 반복되는 일을 보며 AI를 활용하기 시작했습니다.
이곳에는 업무에서 발견한 문제, 만들고 싶은 도구, 직접 배우고 확인한 내용을 기록하려고 합니다.

### 💼 제가 가져오는 경험

| 경험 | 함께할 수 있는 일 |
| --- | --- |
| 제조·유통 및 온라인 판매 업무 | 실제 사용자의 불편과 필요한 기능 정리 |
| 거래처 조사와 해외 영업 제안 준비 | 제품 정보 구성, 영업 흐름 설계, 문구 검토 |
| 고객 문의 대응 | 자주 묻는 질문 정리, 사용자 관점의 테스트 |

ChatGPT와 Codex를 활용해 거래처 조사, 영업메일 초안 작성, 고객 문의 답변 정리를 진행해 봤습니다.
이 경험을 바탕으로, 이제는 작은 기능을 직접 구현하고 이해하는 단계로 나아가고 싶습니다.

### 🌱 지금의 출발점

- **프로그래밍:** 입문 단계입니다. 아직 능숙하게 다루는 언어나 프레임워크는 없습니다.
- **배우고 싶은 것:** GitHub로 작업 기록 남기기, 웹 서비스의 기본 구조, API 연결과 오류 확인.
- **관심 분야:** 소규모 사업자의 업무 자동화, 해외 영업, 고객 문의 정리.
- **협업에서 맡고 싶은 역할:** 문제 정의, 서비스 기획, 실제 업무 사례 설명, 결과 검토.

### 🔎 첫 프로젝트 구상

**해외 영업 보조 도구 · 기획 단계**

제품 정보와 거래처의 특징을 입력하면 영업메일 초안을 만들고,
받은 문의에서 요청사항과 다음 할 일을 정리하는 작은 도구를 구상하고 있습니다.

`제품 정보 입력 → 영업메일 초안 → 사용자 검토 → 받은 문의 요약`

아직 구현하지 않은 아이디어입니다. 먼저 한 가지 업무 흐름을 작게 완성해 보는 것이 목표입니다.
